# AlchemistCraft

**Powerful Custom Recipe Plugin for Minecraft 1.13–26.1.2+**

Supports Spigot, Paper, Purpur.

## Features
- Unlimited custom shaped & shapeless recipes
- Furnace, Blast Furnace, Smoker recipe support
- In-game GUI Recipe Editor
- SQLite, JSON, MySQL storage
- 14 language support
- PlaceholderAPI & Vault integration
- ...and more
